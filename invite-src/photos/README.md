# Photos for the invitation

Upload photographs here (GitHub: **Add file → Upload files**). Any names are fine; for example:

- `susmita.jpg` — Susmita on her own
- `ashish.jpg` — Ashish on his own
- `together.jpg` — the two of them

JPG or PNG, straight from the phone is fine; they are resized and cropped for the photo deck when the page is built.
Portrait (upright) shots with the face well lit work best. This repository is public, so anything here is public too.
