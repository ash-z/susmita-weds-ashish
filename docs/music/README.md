# The invitations' songs

Each invitation plays its own song. Put the files here, named exactly:

- `relatives.mp3`: plays on the relatives' invitation (https://ash-z.github.io/susmita-weds-ashish/)
- `friends.mp3`: plays on the friends' invitation (https://ash-z.github.io/susmita-weds-ashish/friends/)

(`.m4a` or `.wav` also work, e.g. `relatives.m4a`, but `.mp3` plays everywhere; phone recordings in `.opus`/`.ogg`
don't play on iPhones.) Keep each short and small: a 1–3 minute clip, under about 5 MB.

A song starts when a guest taps "Open invitation", loops, and a speaker button next to Ivory/Jewel pauses it.
With no file for an invitation, that invitation stays silent. To change a song, replace its file (same name).
